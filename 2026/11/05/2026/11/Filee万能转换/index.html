Filee 使用指南：拖一下，完成 260+ 种文件格式转换

发表于2026-11-05|更新于2026-11-05|软件推荐
|浏览量:

一句话总结：Filee 把“打开软件 → 导入文件 → 选格式 → 导出”压缩成了“按住键，把文件拖到格式图标上”。它支持图片、PDF、Office、视频、音频、电子书等 260+ 种格式，且全部在本机完成，不上传文件。

一、Filee 是什么？

Filee 是一款免费开源的文件格式转换工具，GitHub 项目是 KnifeLemon/Filee。

它和常见转换软件最大的区别是：不需要先打开一个大窗口。安装后，选中文件，按住 Ctrl（Windows）或 Option（macOS），把文件拖到鼠标旁边的“环形格式菜单”，松手就能转换。

它适合这些场景：

  • 手机拍的 HEIC 照片，转成 JPG 或 WebP 再上传博客；
  • 把 PNG 封面压成 WebP，减小文章图片体积；
  • Word、Excel、PPT 转 PDF；
  • PDF 拆页、合并、压缩，或转成图片；
  • 视频转 MP4、GIF，音频转 MP3、FLAC；
  • EPUB、MOBI、AZW3 等电子书互转；
  • ZIP、7Z、RAR 等压缩包解压和重新打包。

二、为什么值得装？

操作快 拖到格式图标上即可，不用层层点菜单

四、最快上手：3 步转换一个文件

第 1 步：选中文件

在资源管理器/Finder 里选中你要转换的文件。可以一次选多个。

第 2 步：按住快捷键拖动

  • Windows：按住 Ctrl
  • macOS：按住 Option

把文件拖到鼠标位置，Filee 会弹出一个环形菜单。

第 3 步：放到目标格式上

环形菜单只显示“适合当前文件”的格式。比如拖入 photo.heic，会出现 JPG、PNG、WEBP 等选项；把文件放到 JPG 上，松手即可。

转换完成后，结果默认保存在原文件旁边。

小技巧：环形菜单打开时，按 Tab 或滚动鼠标滚轮，可以翻到另一面，看到更多不常用格式和工具。

五、Hexo 博主常用场景

1. 手机照片 HEIC → JPG / WebP

iPhone 照片常是 HEIC，部分浏览器和主题处理不方便。用 Filee 批量转成 JPG 或 WebP，再上传到 Hexo。

2. 封面 PNG → WebP

WebP 通常比 PNG 小很多，适合文章封面和截图。转换时可以在工具栏里调整质量。

3. PDF → PNG

把 PDF 的某一页转成图片，用来做文章配图或教程步骤图。

4. 录屏 MOV → MP4 / GIF

录屏文件太大时，转成 MP4；需要表情包或短演示时，转成 GIF。

5. 文档 → PDF

Word、Excel、PPT 转 PDF，方便在博客里提供下载。

6. Markdown / TXT → PDF

写好的草稿可以转 PDF 存档。复杂排版建议先预览，必要时再手动调整。

六、进阶功能

批量转换

一次选中多个文件，拖到同一个格式上即可。Filee 会并行处理。

裁剪图片

环形菜单里的 Crop 可以逐张打开图片，拖动裁剪框、选择比例，只保存裁剪区域。

从浏览器直接拖

在 Chrome、Edge、Firefox、Safari 里，可以把图片、文件链接或下载项直接拖到 Filee 的环形菜单。Filee 会保存到下载目录并转换。

监视文件夹

设置一个“监视文件夹”，之后放进来的文件会自动按规则转换。适合固定把截图转 WebP、把录音转 MP3 的场景。

七、格式与可选引擎

Filee 官方标称支持 260+ 种格式，常见包括：

类型 常见格式
图片 JPG、PNG、WebP、AVIF、TIFF、BMP、GIF、HEIC、PSD、RAW、SVG
PDF PDF 转 Word、图片、TXT；合并、拆分、压缩
文档 DOCX、DOC、ODT、RTF、TXT、Markdown、HTML
表格 XLSX、XLS、ODS、CSV、TSV、JSON
演示 PPTX、PPT、ODP、Keynote
视频 MP4、MOV、MKV、WebM、AVI、WMV、GIF
音频 MP3、M4A、WAV、FLAC、OGG、OPUS、WMA
电子书 EPUB、MOBI、AZW3、FB2、CBZ
压缩包 ZIP、7Z、RAR、TAR、GZ、ISO
其他 字体、CAD、3D 模型、地理数据

大部分格式开箱即用。少数格式需要可选引擎，第一次用到时 Filee 会提示下载：

  • FFmpeg：视频、音频；
  • LibreOffice：部分 Office/文档格式；
  • Ghostscript：EPS/PS；
  • Pandoc：部分文本格式；
  • calibre：部分电子书格式。

新手不用手动配置，按提示下载即可。如果公司网络有限制，建议提前下载好所需引擎。

八、常见问题

1. 拖了文件没反应？

先确认你是否按住了 Ctrl / Option。如果还是不行，可以：

  • 从 Filee 首页的拖放区拖入；
  • 使用文件管理器右键菜单；
  • 检查 Filee 是否正在运行（托盘/菜单栏）。

2. 转换后的文件在哪？

默认在原文件旁边。可以在 Filee 设置里修改输出目录和文件名规则。

3. 视频转换提示缺少引擎？

第一次转视频/音频需要下载 FFmpeg。等下载完成后再试；不要中途关闭 Filee。

4. PDF 转 Word 后排版乱了？

PDF 不是为编辑设计的，复杂表格、分栏、扫描件转 Word 后排版变化很常见。重要文件先备份，转换后人工校对。

5. Windows 10 打不开 Filee？

先安装最新的 Windows 累积更新。如果仍然打不开，可能是系统 CET 保护与 .NET 的兼容问题，可在 PowerShell（管理员）中执行：

安装程序本身如果也打不开，对安装程序文件名执行同样操作，或改用便携版 ZIP。

6. macOS 提示“无法验证开发者”？

到 系统设置 → 隐私与安全性，选择“仍要打开”。这是预览版尚未公证导致的。

7. Linux 下拖拽没反应？

Wayland 不支持 Filee 的拖拽手势，改用拖放区或右键菜单。

8. 转换后文件变小了，画质会变差吗？

图片和视频默认可能会压缩。转换前可以在工具栏里调整质量、分辨率、码率等参数；重要素材建议保留原文件。

九、隐私与安全

Filee 的转换在本机完成，不上传文件，也不收集使用数据。它只会在以下情况联网：

  • 检查是否有新版本；
  • 下载你选择安装的转换引擎；
  • 你点击外部链接时打开浏览器。

如果不想自动检查更新，可以在 设置 → 关于 里关闭。

即便如此，重要文件仍建议先备份。格式转换不是无损的，尤其是 PDF 转 Word、视频压缩、图片有损压缩。

十、总结

Filee 最适合这些人：

  • 经常处理图片、PDF、Office 文档的人；
  • 不想把文件上传到在线转换网站的人；
  • 需要批量转换、又不想装一堆软件的人；
  • 写博客、做教程，经常要把 HEIC/PNG/PDF 转来转去的人。

如果你只需要偶尔转一张图，在线工具也能用；但如果你经常转换、又在意隐私和效率，Filee 很值得常驻。
